## 2. WCAG 2.2 Level AA Specific Implementations

### 2.1 Focus Not Obscured (Minimum) — Criterion 2.4.11
- **Issue:** Sticky header bars or floating banners can obscure keyboard-focused elements when a user tabs down a page.
- **Implementation in Saans:** All interactive targets, sections, headings, articles, and form controls specify `scroll-margin-top: 5.5rem` in `app/globals.css`. When focused via keyboard, the browser scrolls the element clearly below the sticky header with at least 24px of clearance.

### 2.2 Target Size (Minimum) — Criterion 2.5.8
- **Implementation in Saans:** Every interactive button, link, tab trigger, and form input has a minimum pointer target size of $44 \times 44$ CSS pixels for primary interactions, and at least $24 \times 24$ CSS pixels with sufficient spacing for inline auxiliary controls.

### 2.3 Redundant Entry — Criterion 3.3.7
- **Implementation in Saans:** Users are never prompted to enter the same information twice. The household profile (location, demographic counts, commute distance, purifier status) is saved in client `localStorage` and automatically populates the dashboard, personalized plan, Ask Saans chat grounding, and community pack.

### 2.4 Consistent Help — Criterion 3.2.6
- **Implementation in Saans:** Emergency clinical safety boundaries, the medical disclaimer, and help navigation links are located in identical positions across pages (consistent header navigation and persistent health disclaimer in the footer and `/about`).

## 3. Visual & Cognitive Accessibility

### 3.1 Color Independence (1.4.1 Use of Color)
- Air quality categories (Good, Satisfactory, Moderate, Poor, Very Poor, Severe) are **never conveyed by color alone**.
- Each category is reinforced by:
  1. Plain-text English and Hindi category labels.
  2. Distinct Lucide SVG icons (`Smile`, `CheckCircle`, `AlertCircle`, `AlertTriangle`, `ShieldAlert`, `Flame`).
  3. Visual severity levels (1 to 6).
  4. Specific numeric AQI range indicators.

### 3.2 High-Contrast Ratio Verification (1.4.3 Contrast Minimum)
All text colors measured against background (`#09090b` / `#18181b`):
- Pure white headers (`#ffffff`): **19.8:1** (Exceeds AAA).
- Secondary text (`#a1a1aa` zinc-400): **5.9:1** (Exceeds AA 4.5:1).
- Green category text (`#4ade80`): **9.8:1**.
- Amber / Yellow category text (`#facc15`): **11.2:1**.
- Orange category text (`#fb923c`): **7.1:1**.
- Red category text (`#f87171`): **6.7:1**.
- Rose category text (`#fb7185`): **7.2:1**.
- Primary CTA buttons (`bg-emerald-700` `#047857` with white text): **4.64:1** (Exceeds 4.5:1).

### 3.3 Plain-Language Rules & Jargon Explanations
Every technical term is explained in plain language in one sentence on first use:
- **AQI (Air Quality Index):** *"A score from 0 to 500 measuring how clean or polluted the air is—higher numbers mean greater health risk."*
- **PM2.5 (Fine Particulate Matter):** *"Microscopic toxic dust particles smaller than 2.5 microns (30 times thinner than a human hair) that enter deep into lungs and the bloodstream."*
- **Temperature Inversion:** *"A cold weather trap where heavy, stagnant cold ground air traps smoke and exhaust like a lid until midday sunshine warms the ground."*

## 5. Web Speech API (Read-Aloud) Support
The Personalised Plan and Ask Saans Chat components provide a one-click audio read-aloud button utilizing the browser's native `window.speechSynthesis`. When the page language is set to Hindi, speech synthesis automatically selects the `hi-IN` Indian Hindi voice; when set to English, it selects `en-IN` or `en-US`.
