# Saans (साँस) — Breathe Smarter Through Smog Season

> Production-grade, GenAI-powered clean-air assistant and community smog mitigation platform designed for Indian urban families and Resident Welfare Associations (RWAs / societies), calibrated against Delhi-NCR winter smog conditions.

## 3. Quickstart & Setup

### Prerequisites
- Node.js 18.17+ or 20+
- npm (or pnpm/yarn)

### Installation
```bash
git clone https://github.com/example/saans.git
cd saans
npm install
```

### Environment Configuration
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```

Edit `.env.local`:
```env
# Optional for full GenAI features. If not provided, Saans automatically runs in deterministic rule mode.
GEMINI_API_KEY=your_gemini_api_key_here

# Configurable Gemini model identifier (never hardcoded in source)
GEMINI_MODEL=gemini-2.0-flash

# Environment
NODE_ENV=development

# Optional Rate Limiting Overrides (requests per 60-second window per IP)
RATE_LIMIT_PER_MINUTE=60
```

### Running Locally
```bash
# Start development server
npm run dev

# Open http://localhost:3000 in your browser
```

## 5. Architectural Assumptions & Limitations

1. **Ambient Air Quality Data Source:** Real-time ambient particulate concentrations and 24-hour forecasts are sourced from Open-Meteo's hourly Copernicus/CAMS model dataset. While highly accurate for regional urban patterns, micro-local anomalies (e.g. adjacent trash burning) may vary.
2. **In-Memory Rate Limiting:** Rate limiting uses a sliding-window token bucket stored in memory. In multi-region serverless deployments, this can be swapped with Redis/Upstash via the same typed `RateLimiter` interface.
3. **No Database / Zero PII Storage:** User profiles, sensitivity flags, and commute preferences exist exclusively in client `localStorage`. The server remains stateless and retains no identifying user data.
4. **Clinical Boundaries:** Saans is strictly an ambient exposure advisory tool. It does not provide medical diagnosis, prescription advice, or inhaler regimen changes.
